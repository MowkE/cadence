How this is counted

  • The live part is read from GitHub each time this page loads. It adds up the installer files of every public release, which are the .exe, .dmg and .AppImage files.
  • GitHub drops a file's count when the file is deleted. The installers of the oldest versions were removed, so their downloads are the count Cadence recorded before that. That part cannot be checked on GitHub today.
  • Update check files and patch files are left out.
  • A download is not a person. Someone who installs several versions is counted once for each.
  • You can check it yourself on the releases page or in the same list straight from GitHub, where each file has a download_count.
