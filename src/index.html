Cadence already reads the Spotify app on this computer — you can close this. API keys are optional: they add following playback on your other devices and, on Windows, playing along in a friend's session. Spotify requires Premium to create an app (since Feb 2026).

Cadence reads what you're playing through Spotify's API with your own keys. Spotify requires a Premium account to create an app.

  2. Add http://127.0.0.1:8888/callback as the Redirect URI
  3. Paste your app's keys below — they stay on this computer
